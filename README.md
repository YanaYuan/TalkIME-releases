# TalkIME

Windows 全局 AI 语音输入：在任意输入框中按一下 **右 Alt** 开始，说完再按一次结束，按 **空格** 插入到光标处。无需替换搜狗、微信、双拼或五笔等现有输入法。

## 下载

从 [Releases 页面](https://github.com/YanaYuan/TalkIME-releases/releases/latest)下载最新版安装包。

- Windows 10 / 11
- 安装到当前用户目录，无需管理员权限
- 当前免费使用
- v1.2.3 安装包及主程序、辅助程序、卸载程序均已加入数字签名
- 使用原生聊天回复窗口，无需额外安装 WebView2 Runtime

## 第一次使用

1. 安装并启动 TalkIME，使用 Microsoft 账号登录。
2. 把光标放进 Cursor、Claude Code、Word、浏览器等任意输入框。
3. 按一下 **右 Alt** 开始，说完再按一次结束；按 **Tab** 切换结果，按 **空格** 插入，按 **Esc** 放弃。
4. 结果卡显示时，可再次点按 **右 Alt**，直接说出修改要求。

## 聊天回复

[观看 26 秒演示：问进展，只说一句中文](https://yanayuan.github.io/TalkIME-releases/#chat-reply)。演示沿用此前的情景画面，当前版本通过手动框选截图获取上下文。

1. 打开要回复的对话，点按 **右 Shift**，手动框选需要参考的聊天画面并确认。快捷键可在设置中更改。
2. 多模态大模型直接读取确认的截图。点按 **右 Alt** 说出回复要求，再按一次结束；也可点击“帮我想回复”。
3. 查看草稿，按 **右 Alt** 继续提出修改要求；确认后按 **Space** 上屏，按 **Esc** 取消。不会自动发送聊天消息。
4. 点击“聊天记录”查看截图预览；卡片非交互区域可拖动，草稿和语音原文可选中复制。

## 更新与卸载

- 支持自动更新的 EXE 版会在启动时后台检查并下载；下载完成后，从托盘退出并再次启动以安装新版。商店版走商店更新渠道。
- 手动覆盖安装无需先卸载。手动安装或卸载前，请先从托盘退出 TalkIME，避免文件占用。
- 数字签名不保证所有安全软件均不提示；如遇拦截，请保留提示和发布者信息，不要关闭安全防护。

## 数据处理说明

- 语音识别与 AI 整理通过云端服务完成。
- 光标前文默认开启，屏幕语境默认关闭；启用后，相关上下文会发送到云端模型用于本次处理。
- 截图回复会将确认选区的图片、语音要求及修改上下文发送到 TalkIME 后端和云端多模态模型，用于生成回复。请仅选择必要内容，并核对草稿。
- 客户端运营埋点只记录耗时、字数、结果状态等数值或枚举，不记录转写正文、个人词条或屏幕内容。
- 下载页使用 Microsoft Clarity 进行无 Cookie 的访问、来源与点击统计，不设置持久访客标识。
- 当前客户端到 TalkIME 后端仍使用 HTTP，请勿处理高度敏感内容。详见[隐私政策](https://yanayuan.github.io/TalkIME-releases/privacy.html)。
